# Монетизация

Все три потока реализованы поверх одной платёжной механики Telegram Stars: `createInvoiceLink(currency: XTR)` → `WebApp.openInvoice()` → webhook `pre_checkout_query` → `successful_payment` → выдача. Таблицы: `products`, `transactions` (идемпотентность по `invoice_payload` и `tg_charge_id`), `subscriptions`, `inventory`.

## 1. Premium-подписка — 250 ⭐/мес

Даёт: отключение рекламы (сервер возвращает `ad: null`), кастомные сакс-ремиксы будильника (`users.custom_sound`, меняется только при `is_premium`), расширенную статистику, эксклюзивные бейджи (`badges.premium_only`), сквад до 25 человек вместо 10. Продление стекается: повторная покупка прибавляет 30 дней к `premium_until`. Истечение проверяется по полю, флаг снимается ленивым cron-ом.

## 2. Разовые покупки (Stars)

Заморозка стрика 🧊 50⭐ — записывает сегодняшнюю дату как «пил», стрик не сгорает. Пропуск будильника 🔕 30⭐ — гасит активный будильник без дринка. Буст лидерборда 🚀 100⭐ — очки ×2 до конца дня (ключ `boost:{user}:{date}` в Redis, лидерборд честно помечает бустеров — соцдавление против pay-to-win). Косметика 💜🏆 75–150⭐ — рамки профиля. Всё лежит в `inventory`, списывается атомарным `UPDATE ... qty-1 WHERE qty>0`.

## 3. Партнёрская реклама (бары и бренды)

Форматы (`ad_campaigns.kind`): **drink_of_week** — нативная карточка «Напиток недели» в ленте главного экрана; **coupon** — купон бара-партнёра с промокодом, редим фиксируется событием; **leaderboard_slot** — слот в ленте лидерборда (спонсор видит самых активных); **squad_challenge** — спонсируемый челлендж сквадов («сквад, сделавший 50 дринков за уикенд, получает столик в X»), условия — в `meta`.

Механика показа: слот запрашивается фронтом по placement, сервер отдаёт активную кампанию с наименьшим числом показов за сегодня (равномерная ротация), уважая `daily_cap`; premium исключён. Каждый факт пишется в `ad_events`: impression, click, coupon_redeem, challenge_join, challenge_done.

Метрики рекламодателю (`GET /api/ads/:id/metrics`): показы/клики/редимы, тотал и уникальные пользователи, CTR. Для баров ключевая метрика — coupon_redeem (фактический приход ноги в бар), для брендов — CTR и охват челленджей. Модель продажи: фикс за неделю кампании + бонус за редимы; в проде добавить гео-таргетинг (город в `meta`) и дашборд.

Этическое ограничение: реклама помечена «Партнёр», в челленджах и купонах не поощряется превышение разумных объёмов — лимиты антифрода (8 дринков/день) действуют и на спонсируемые челленджи.
